# 🧹 SweepX

**免费、开源、纯本地的 X (Twitter) 批量清理工具**

[English](./README_EN.md) | 中文

一键批量删除你的推文 / 转推 / 引用 / 回复 —— 数据永不出本机，无服务器、无追踪、无付费墙。

</div>

## ✨ 功能特性

- **📦 归档全量清理** — 拖入 X 官方数据包（zip 或 tweets.js），一次性清理全部历史
- **⚡ 在线扫描清理** — 在个人主页自动滚动扫描，适合清理近期数据，无需等待归档下载
- **🎯 四类精准分类** — 原创发帖 / 转推 / 引用 / 回复，分类调用对应删除接口（转推走 Unretweet）
- **🔍 多维筛选** — 日期范围、保留高赞推文、关键词白名单，防误删
- **🧪 Dry-Run 模拟模式** — 不真实调用接口，先看会删什么
- **⏯ 断点续删** — 页面/浏览器意外关闭后，从上次中断处一键继续
- **🧠 queryId 自动学习** — 自动捕获页面最新接口参数，X 改版不用等扩展更新
- **🛡 防封流控** — 拟人化随机延迟、批次冷却、429 指数退避、连续限速自动熔断
- **💾 CSV 备份** — 删除前一键导出完整备份
- **🔒 100% 本地运行** — 无后端、无上报，账号凭据只用于本机发删除请求

## 📦 安装

1. 下载本仓库（`Code → Download ZIP` 并解压，或 `git clone`）
2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角**开发者模式**
4. 点击**加载已解压的扩展程序**，选择本项目的 `extension/` 目录
5. 浏览器登录 x.com 后，扩展图标**亮起**即代表会话就绪

> 也提供油猴脚本版本（`userscript/sweepx.user.js`），配合 Tampermonkey 使用。

## 🚀 使用指南

### 方式一：归档全量清理（推荐用于大扫除）

1. X → Settings → Your account → **Download an archive of your data**（生成需数小时到 24h+）
2. 打开 SweepX → 「归档包」标签 → 拖入下载的 `.zip`
3. 选择要清理的类型、设置筛选条件
4. **先勾选 Dry-Run 跑一轮**，核对数量
5. 取消 Dry-Run，真实执行（保持页面开启，任务自动分批冷却推进）

### 方式二：在线扫描（适合近期数据）

1. 在浏览器打开你的 x.com 个人主页
2. 清理**原创/转推** → 停在「帖子」标签页；清理**回复** → 切到「回复」标签页
3. 点击「自动扫描当前页面推文」，扫描深度可调（默认 8 次 ≈ 40-80 条）
4. 扫描完成后选择类型 → 删除

### 断点续删

任务启动后即自动保存进度。页面意外关闭后重新打开扩展，顶部会出现
「检测到未完成任务：已处理 X/Y」，点「继续」从断点接着删。

### queryId 自动学习

X 会不定期更换内部接口 ID。SweepX 会自动监听页面自身的删除请求并学习最新参数。
**首次使用前，请在 x.com 上手动删除任意一条推文**（一次即可，长期有效；X 改版后重新删一条即可重新学习）。

## ❓ FAQ

<details>
<summary>删除报 403 / 认证错误？</summary>

确认浏览器已登录 x.com，然后在扩展里点「刷新凭据」重新获取会话。
</details>

<details>
<summary>删除报 404？</summary>

说明接口参数已过期（X 改版）。到 x.com 手动删除一条推文，让 SweepX 重新学习 queryId，然后重试。
</details>

<details>
<summary>删除速度有多快？</summary>

出于账号安全考虑，采用"慢即是快"策略：约每分钟 15-20 条，每 60 条冷却 15 分钟。
500 条 ≈ 2-3 小时，5000 条 ≈ 1-2 天，数万条 ≈ 数天（挂着不用管）。
</details>

<details>
<summary>会封号吗？</summary>

通过内部接口自动化操作技术上违反 X 服务条款。SweepX 的流控设计（随机延迟/冷却/退避）
尽量模拟人类节奏以降低风险，但**无法承诺零风险**，请自行评估，建议小批量试水后再放量。
</details>

## 🔒 隐私

- 所有解析、筛选、删除请求均在**你的浏览器本地**完成，不经过任何第三方服务器
- 扩展读取 x.com 的 `ct0` / `auth_token` Cookie **仅用于**本机构造删除请求，不做任何存储或上传
- 归档文件只在本地解析，不会发送到任何地方
