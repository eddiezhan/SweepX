# 🧹 SweepX

**免费、开源、纯本地的 X (Twitter) 批量清理工具**

[English](./README_EN.md) | 中文

批量删除你的推文 / 转推 / 引用 / 回复，批量取消关注 —— 数据永不出本机，无服务器、无追踪、无付费墙。

## ✨ 功能特性

- **📦 归档全量清理** — 拖入 X 官方数据包（zip 或 tweets.js），一次性清理全部历史
- **⚡ 在线扫描清理** — 直接读取页面加载的官方接口数据（非猜测 DOM），分类精确、互动数真实，扫描结果自动合并累积，支持设置滚动深度
- **👥 批量取关** — 「演示学习」架构：手动取关 1 人即可学会取关接口，然后勾选列表批量执行（默认全选、昵称显示、限速重放）
- **🎯 四类精准分类** — 原创发帖 / 转推 / 引用 / 回复，转推走 Unretweet 接口，其余走 DeleteTweet
- **🔍 多维筛选** — 日期范围、保留高赞/高转推、关键词白名单，防误删
- **✅ 勾选排除** — 大屏预览表格逐条勾选，取消勾选的推文保留不删（默认全选）
- **🧪 Dry-Run 模拟模式** — 不真实调用接口，先看会删什么
- **⏯ 断点续删** — 队列与进度实时持久化，页面/浏览器意外关闭后一键从断点继续
- **🧠 接口参数自学习** — 自动捕获页面自身的删除请求与接口 ID，X 改版无需等扩展更新；首次删除成功后自动固化
- **🛡 防封流控** — 拟人化随机延迟、批次冷却（60 条/15 分钟）、429 指数退避、连续限速自动熔断
- **🗑 删除即出清** — 已删除的项自动从待删列表移除，按钮计数实时更新
- **🖥 大屏控制台** — 弹窗点「↗ 大屏」进入：在线扫描 / 批量取关 / 归档清理三合一，大预览表格、共享执行台、跟随标签的实时日志
- **🔔 图标状态** — 登录 x.com 时工具栏图标亮起，登出变暗
- **💾 CSV 备份** — 删除前一键导出完整备份
- **🔒 100% 本地运行** — 无后端、无上报，账号凭据只用于本机发请求

## 📦 安装

1. 下载本仓库（`Code → Download ZIP` 并解压，或 `git clone`）
2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角**开发者模式**
4. 点击**加载已解压的扩展程序**，选择本项目的 `extension/` 目录
5. 浏览器登录 x.com 后，扩展图标**亮起**即代表会话就绪

> 也提供油猴脚本版本（`userscript/sweepx.user.js`），配合 Tampermonkey 使用。

## 🖒 两种界面怎么选

| | 弹窗（点扩展图标） | 大屏（弹窗内点「↗ 大屏」） |
|---|---|---|
| 适合 | 快速小批量 | 深度扫描、大批量、需要看预览表格 |
| 在线扫描 / 取关 / 归档 | ✅ 三合一 | ✅ 三合一 |

> 大屏的「删除执行台」为在线扫描和归档两个标签共享——扫完当场就能删，不用跳转。

## 🚀 使用指南

### 方式一：归档全量清理（推荐用于大扫除）

1. X → Settings → Your account → **Download an archive of your data**（生成需数小时到 24h+）
2. 「归档清理」标签 → 拖入下载的 `.zip`
3. 选择类型、设置筛选（日期 / 保留高赞 / 关键词白名单）
4. **先勾选 Dry-Run 跑一轮**，核对预览数量
5. 取消 Dry-Run，真实执行（保持页面开启，任务自动分批冷却推进，关掉后可断点续删）

### 方式二：在线扫描（适合近期数据）

1. 在浏览器打开你的 x.com 个人主页（「帖子」或「回复」页均可）
2. 点扫描 —— SweepX 会**自动刷新该页面**并读取页面加载的官方接口数据，分类与互动数精确无误
3. 滚动深度可调（默认 8 次 ≈ 40-80 条）；多次扫描结果按 ID 自动合并
4. 扫描页直接勾类型执行删除，或在大屏查看预览表格后执行

### 方式三：批量取关

1. 打开你的「关注」列表页（左侧导航 → 关注），**刷新一次页面**
2. **手动取关任意 1 人**——这教会 SweepX 当前的取关接口（学完可以再关注回去）
3. 回到扩展 → 「👥 批量取关」→「📋 读取已捕获的关注列表」
4. 勾选要取关的人（默认全选）→「🚫 开始取关」
5. 每次间隔 3-6 秒，触发频率限制会自动停止；成功的人自动移出列表，失败的保留可重试

### 断点续删

任务启动后即自动保存进度。页面意外关闭后重新打开扩展或大屏，顶部会出现
「检测到未完成任务：已处理 X/Y」，点「继续」从断点接着删；跑完自动清档，也可手动「放弃」。

### 接口参数自学习

X 会不定期更换内部接口 ID。SweepX 三重自适应：

1. **页面嗅探**：自动监听页面自身发出的删除请求，学习最新参数（在 x.com 上手动删一条推文即可）
2. **成功自举**：SweepX 自己删除成功一次后，同样会把可用参数固化下来
3. **内置兜底**：以上都没有时使用内置参数，失败时日志会显示 X 的原始响应

## ❓ FAQ

<details>
<summary>删除报 403 / 认证错误？</summary>

确认浏览器已登录 x.com，然后在扩展里点「刷新凭据」重新获取会话。
</details>

<details>
<summary>删除报 404 或“假成功”？</summary>

接口参数已过期（X 改版）。到 x.com 手动删除一条推文让 SweepX 重新学习，然后重试。
SweepX 对“200 但没有真实删除效果”的响应会直接判失败并显示原始内容，不会静默骗你。
</details>

<details>
<summary>在线扫描扫不到数据 / 提示“页面解析兜底”？</summary>

点扫描时 SweepX 会自动刷新 x.com 页面以激活数据捕获。若仍提示兜底模式，手动 F5 刷新
x.com 后重扫。兜底模式下回复识别不可用（X 页面已不渲染回复标识）。
</details>

<details>
<summary>取关时提示“取关接口未学习”？</summary>

页面刷新会清空已学习的状态。在「关注」列表页刷新后手动取关 1 人，再点「读取」。
读取后日志会显示捕获到的候选接口与最近请求，一目了然。
</details>

<details>
<summary>删除速度有多快？</summary>

出于账号安全考虑，采用“慢即是快”策略：约每分钟 15-20 条，每 60 条冷却 15 分钟。
500 条 ≈ 2-3 小时，5000 条 ≈ 1-2 天，数万条 ≈ 数天（挂着不用管）。
</details>

<details>
<summary>会封号吗？</summary>

通过内部接口自动化操作技术上违反 X 服务条款。SweepX 的流控设计（随机延迟/冷却/退避）
尽量模拟人类节奏以降低风险，但**无法承诺零风险**，请自行评估，建议小批量试水后再放量。
</details>

## 🔒 隐私

- 归档文件只在本地解析，不会发送到任何地方
