# deleteX 🧹

> **0 成本、保护隐私、突破 3200 条限制的 X (Twitter) 批量历史推文清理系统**  
> 支持独立或组合批量删除：**原创发帖 (Posts)**、**转发/转推 (Retweets)**、**引用发帖 (Quotes)** 与 **回复 (Replies)**。

---

## 💡 一、 为什么市面上的工具要么收费，要么删不干净？

1. **官方 API 商业化收费**：
   - X (Twitter) 在 API v2 之后取消了有实际意义的免费写/删权限。官方推文删除接口（`DELETE /2/tweets/:id`）按量计费，**单条删除约收取 \$0.01 美元**。删除 10,000 条推文仅 API 账单就需 \$100 美元！
2. **官方 API 的 3,200 条检索上限**：
   - 官方在线检索接口（`GET /2/users/:id/tweets`）最多只能回溯用户最近的 **3,200 条推文**。如果你的账号注册多年，早期的历史推文在官方在线接口中根本查不到。
3. **第三方付费清理服务的隐私隐患**：
   - 市面上的 TweetDeleter、Redact 等工具采用高额月费/年费订阅制，并且要求用户上传数据或授权完整的写入权限给第三方服务器，存在密码泄露和账号被风控的风险。

## ⚡ 二、 deleteX 的核心解决方案

本项目采用 **“本地数据归档解析 + 浏览器原生会话 (Session) + 内部 GraphQL 协议”** 架构，实现：

| 核心特性 | deleteX 解决方案 |
| :--- | :--- |
| **0 成本 (100% 免费)** | 直接复用浏览器在 `x.com` 登录后的免费 Web 内部 GraphQL 协议，**不产生任何 API 账单** |
| **100% 全量清理** | 本地解析 X 官方归档数据（`tweets.js`），覆盖从注册第一天起的所有推文，**彻底突破 3,200 条上限** |
| **四大类型精准区分** | 原创发帖、转推、引用、回复分别识别，针对“转推”自动提取原推 ID 并调用 `DeleteRetweet` |
| **保护隐私安全** | **数据不出本地**！无后端服务器，无任何第三方数据收集，代码 100% 开源可审计 |
| **高阶风控防封** | 采用拟人化随机抖动延时（`2.5s ~ 4.5s`）+ 滑动窗口批次休眠（每 60 条休眠 15 分钟）+ HTTP 429 自动指数退避熔断 |

## 🔍 三、 四大类型推文的技术判定与删除机理

在 Twitter 官方归档包的 `tweets.js` 中，各类型特征及调用接口如下：

```
                    ┌─── full_text 以 "RT @" 开头 ───> 【转发 Retweet】 ──> DeleteRetweet(source_tweet_id)
                    │
推文对象 (tweet) ───┼─── in_reply_to_status_id 存在 ──> 【回复 Reply】   ──> DeleteTweet(tweet_id)
                    │
                    ├─── quoted_status_id 存在 ───────> 【引用 Quote】   ──> DeleteTweet(tweet_id)
                    │
                    └─── 其它 ─────────────────────────> 【原创 Post】    ──> DeleteTweet(tweet_id)
```

> ⚠️ **关键技术点**：取消转推（Unretweet）在 X 底层必须传入被转推的**原推文 ID (`source_tweet_id`)**，如果传入自己账号下的转发 ID 调用 `DeleteTweet` 会报 404/错误。`deleteX` 内置解析器已自动处理该映射。

## 🚀 四、 使用指南

### 准备工作：获取推文归档包 (Twitter Archive)
1. 打开 [X (Twitter) 设置](https://x.com/settings/your_twitter_data) -> **您的账号 (Your Account)** -> **下载数据归档 (Download an archive of your data)**。
2. 验证身份并提交申请（通常需要 24~48 小时生成）。
3. 收到 X 的邮件通知后，下载 `.zip` 压缩包并解压，在解压后的 `data/` 目录下找到 `tweets.js`。

---

### 方式 A：Chrome / Edge 浏览器扩展 (强烈推荐 ⭐⭐⭐⭐⭐)

提供完整的全功能图形化控制台、数据分析看板、高赞推文保护、模拟测试模式（Dry-Run）与 CSV 备份导出。

#### 安装步骤：
1. 打开 Chrome / Edge 浏览器，进入扩展管理页面（地址栏输入 `chrome://extensions/`）。
2. 在右上角开启 **“开发者模式” (Developer mode)**。
3. 点击左上角 **“加载已解压的扩展程序” (Load unpacked)**。
4. 选择本项目中的 `extension` 目录。
5. 点击浏览器右上角插件栏的 `deleteX` 图标，点击 **“打开完整控制台”**。

#### 使用步骤：
1. 在控制台中拖入你的 `tweets.js` 文件。
2. 系统自动解析并展示饼图/卡片统计（原创/转推/引用/回复各自数量）。
3. 按需配置筛选规则：
   - 勾选想删除的类型（如：只删回复和转推，保留原创发帖）。
   - 设置时间范围（如：仅删除 2 年以前的内容）。
   - 设置保留阈值（如：点赞 ≥ 50 的精华推文保留不删）。
   - 关键词白名单（包含指定词的内容不删）。
4. （强烈推荐）先点击 **“导出备份 CSV”**，留下一份本地永久备份。
5. （可选）勾选 **“模拟测试模式 (Dry-Run)”** 体验删除调度流程。
6. 点击 **“🚀 开始批量清理”**，即可挂机运行。

---

### 方式 B：油猴脚本 (Tampermonkey) (轻量即用 ⭐⭐⭐⭐)

适合不想加载扩展程序、希望直接在 `x.com` 网页内操作的用户。

1. 在浏览器安装 [Tampermonkey (油猴插件)](https://www.tampermonkey.net/)。
2. 新建脚本，将本项目 `userscript/deletex.user.js` 的完整代码复制并保存。
3. 刷新 `x.com` 网页，右下角会出现浮动按钮 **`🧹 deleteX`**。
4. 点击按钮唤出弹窗，选择 `tweets.js` 即可在当前页面内直接执行清理。

## 🛡️ 五、 账号安全与防封风控建议

为了避免被 X 平台风控系统检测为滥用或恶意刷接口，请务必遵守以下建议：
1. **不要修改并调小单条延时**：系统默认设置了 `2.0s ~ 4.5s` 的随机人类模拟延时，请勿调至 1 秒以下。
2. **遵守批次休眠**：系统默认每执行 60 条会自动休眠 15 分钟（匹配 X 的 15 分钟滑动频率窗口）。如果推文总量较大（如几万条），建议挂机在后台慢慢跑，切忌追求极速。
3. **遇到 429 自动等待**：若触发 429 限流提示，系统会自动启动 15~30 分钟退避休眠，切勿连续手动刷新重试。
